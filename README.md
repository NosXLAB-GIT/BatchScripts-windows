# 🧰 NosXTools
**Kho công cụ `.bat` đa năng cho Windows.**  
**A versatile `.bat` script toolkit for Windows.**

---

## 🎯 Mục tiêu  
**Goal**

Tập hợp các batch script (file `.bat`) tối ưu để hỗ trợ xử lý sự cố, tự động hóa tác vụ và tinh chỉnh hệ thống Windows – giúp tăng hiệu suất, giảm lỗi và tiết kiệm thời gian.  
A collection of optimized batch scripts (`.bat`) designed to automate tasks, fix Windows issues, and improve overall system performance.

---

> 📌 *Mỗi script đều được chú thích rõ ràng, dễ hiểu và có thể tùy chỉnh theo nhu cầu.*  
> *Each script is clearly commented, easy to understand, and customizable as needed.*

---

## ⚙️ Hướng dẫn sử dụng  
**Usage Guide**

1. **Tải về** file `.bat` mong muốn từ repository này.  
   **Download** the desired `.bat` file from this repository.  

2. **Chuột phải** vào file → chọn **"Run as administrator"** *(nếu script yêu cầu quyền hệ thống)*.  
   **Right-click** the file → select **"Run as administrator"** *(if admin rights are required)*.  

3. Làm theo hướng dẫn hiển thị trên màn hình.  
   Follow the on-screen instructions.

> 🔎 *Lưu ý:* Nếu Windows không hiển thị đuôi file `.bat`, hãy bật **File name extensions** trong **File Explorer**.  
> *Note:* If `.bat` extensions are hidden, enable **File name extensions** in **File Explorer**.

**Notes**
